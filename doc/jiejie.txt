                                    JIEJIE

                                                                        *jiejie*
Jiejie is a Jujutsu frontend in the style of fugitive.

For further examples, see https://github.com/jceb/jiejie.nvim.

INSTALLATION                                                      *jiejie-intro*

CONFIGURATION                                                    *jiejie-config*

COMMANDS                                                       *jiejie-commands*

                                                                     *jiejie-:J*
:J [args]               Same as :Jj, but one character shorter.

                                                                *jiejie-summary*
:Jj                     With no arguments, bring up a log window. If a summary
                        window is already open for the current repository, it
                        is focused instead.
                        Press g? or see |jiejie-maps| for usage.

                                                                           *:Jj*
:Jj {args}              Run an arbitrary git command and display any output.

MAPS                                                               *jiejie-maps*

                                                                  *jiejie_<C-a>*
<C-a>                   Increase the number of displayed log revisions.

                                                                  *jiejie_<C-x>*
<C-x>                   Decrease the number of displayed log revisions.

                                                                      *jiejie_=*
=                       Toggle an inline diff of the change or file under the
                        cursor.

                                                                   *jiejie_<CR>*
<CR>                    Edit change or file under the cursor.


                                                                  *jiejie_!<CR>*
!<CR>                   Edit immutable change or file under the cursor.

                                                                     *jiejie_g?*
g?                      Show help for |jiejie-maps|.

                                                                     *jiejie_cc*
cc                      Commit currently edited change and create a new
                        change.

                                                                     *jiejie_cn*
cn                      Create a new change after the change under the cursor.

                                                                    *jiejie_crc*
crc                     Revert the commit under the cursor.

                                                                     *jiejie_cs*
cs                      Squash current changes into it's parent.

                                                                    *jiejie_!cs*
!cs                     Squash current changes into it's immutable parent.

                                                                     *jiejie_cS*
cS                      Squash current changes into the selecated change.

                                                                    *jiejie_!cS*
!cS                     Squash current changes into the immutuable selecated
                        change.

                                                                     *jiejie_dd*
dd                      Edit first line of change description.

                                                                    *jiejie_!dd*
!dd                     Edit first line of an immutable change description.

                                                                     *jiejie_de*
de                      Edit change description.

                                                                    *jiejie_!de*
!de                     Edit immutable change description.

                                                                      *jiejie_p*
p                       Fetch changes from remote.

                                                                      *jiejie_P*
P                       Push changes to remote.

                                                                      *jiejie_X*
X                       Abandon change or restore file from parent change.

                                                                     *jiejie_!X*
!X                      Abandon immutuable change or restore file from parent
                        change.
