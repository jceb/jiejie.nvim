                                    JIEJIE

                                                                        *jiejie*
Jiejie is a Jujutsu frontend in the style of fugitive.

For further examples, see https://github.com/jceb/jiejie.nvim.

INSTALLATION                                                      *jiejie-intro*

CONFIGURATION                                                    *jiejie-config*

COMMANDS                                                       *jiejie-commands*

                                                                            *:J*
:J [args]               Same as :Jj, but one character shorter.

                                                                *jiejie-summary*
:Jj                     With no arguments, bring up a log window. If a summary
                        window is already open for the current repository, it
                        is focused instead.
                        Press g? or see |jiejie-maps| for usage.

                                                                      *:Jj* *:Jj!*
:Jj[!] [args]            Run an arbitrary jj command and display any output.
                        With <bang>, add `--ignore-immutuable` to the command.

                                                                   *:Jdiffsplit*
:Jdiffsplit [object]    Perform a |vimdiff| against the given file, or if a
                        commit is given, the current file in that commit. With
                        no argument, the version of the direct ancestors is
                        used, and the work space version is always placed to
                        the right or bottom, depending on available width.
                        Use Vim's |do| and |dp| to stage and unstage changes.

                                                                  *:Jdiffsplit!*
:Jdiffsplit!            Diff against any and all direct ancestors, retaining
                        focus on the current window.  During a merge conflict,
                        this is a three-way diff against the "ours" and
                        "theirs" ancestors.
                        TODO: Additional d2o and d3o maps are provided to
                        obtain the hunk from the "ours" or "theirs" ancestor,
                        respectively.

:Jdiffsplit! {object}   Like |:Jdiffsplit|, but retain focus on the current
                        window.

                                                                  *:Jvdiffsplit*
:Jvdiffsplit [object]   Like |:Jdiffsplit|, but always split vertically.

                                                                  *:Jhdiffsplit*
:Jhdiffsplit [object]   Like |:Jdiffsplit|, but always split vertically.

                                                                        *:Jedit*
:Jedit [object]         |:edit| a |jiejie-object|.

                                                                      *jiejie-d*
Diff maps ~

                                                                     *jiejie_d?*
d?                      Show this help.

                                                                      *jiejie_=*
=                       Toggle an inline diff of the change or file under the
                        cursor.

                                                                     *jiejie_dD*
dD                      Perform a :Jdiffsplit on the file and change under the
                        cursor. The file under the cursor is compared to all
                        its direct ancestors.
                                                                     *jiejie_dd*
dd                      Perform a :Jdiffsplit on the file under the cursor and
                        change @.
                        If the cursor is on the currently edited change `@`,
                        the file is compared to the revisions of all direct
                        ancestors.
                        If the cursor is on a file in another change, then
                        that file's version is compared to the same file in
                        the currently edited change.

                                                                     *jiejie_dV*
dV                      Perform a |:Jvdiffsplit| on the file under the cursor.
                        See |jiejie_dD|.

                                                                     *jiejie_dv*
dv                      Perform a |:Jvdiffsplit| on the file under the cursor
                        and change @. See |jiejie_dd|.

                                                           *jiejie_dS* *jiejie_dH*
dS                      Perform a |:Jhdiffsplit| on the file under the cursor.
dH                      See |jiejie_dD|.

                                                           *jiejie_ds* *jiejie_dh*
ds                      Perform a |:Jhdiffsplit| on the file under the cursor
                        and dh change @. See |jiejie_dd|.

                                                                     *jiejie_dq*
dq                      Close all but the currently focused diff buffer, and
                        invoke |:diffoff|!.

SPECIFYING OBJECTS                               *jiejie-object* *jiejie-revision*

Jiejie objects are either work space files or Jujutsu revisions as defined in
the "Operators" section in the jj documtenation,
https://docs.jj-vcs.dev/latest/revsets/, with expansions inspired by
|cmdline-special| layered on top. For commands that accept an optional object,
the default is the file in the index for work tree files and the work tree
file for everything else. Example objects follow.

Object          Meaning ~
@               The change referenced by @ aka HEAD
main            The change referenced by main
:               The |jiejie-summary| buffer
:./main         The file named main in the working directory
:Makefile       The file named Makefile in the work tree
:%              The current file in the work tree
@-:%            The current file in the parent of HEAD
@--:%           The current file in the grandparent of HEAD
<cfile>         The file or change under the cursor

Not yet implemented:

:(top)main      The file named main in the work tree
:1:%            The current file's common ancestor during a conflict
:2:#            The alternate file in the target branch during a conflict
:3:#5           The file from buffer #5 in the merged branch during a conflict
