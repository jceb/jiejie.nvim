                                    JIEJIE

                                                                        *jiejie*
Jiejie is a Jujutsu frontend in the style of fugitive.

For further examples, see https://github.com/jceb/jiejie.nvim.

INSTALLATION                                                      *jiejie-intro*

CONFIGURATION                                                    *jiejie-config*

COMMANDS                                                       *jiejie-commands*

                                                                            *:J*
:J [args]               Same as :Jj, but one character shorter.

                                                                *jiejie-summary*
:Jj                     With no arguments, bring up a log window. If a summary
                        window is already open for the current repository, it
                        is focused instead.
                        Press g? or see |jiejie-maps| for usage.

                                                                           *:Jj*
:Jj {args}              Run an arbitrary git command and display any output.

                                                                        *:Jedit*
:Jedit [object]         |:edit| a |jiejie-object|.

                                                        *jiejie-navigation-maps*
Navigation maps ~

                                                                   *jiejie_<CR>*
<CR>                    Edit change or file under the cursor.


                                                                  *jiejie_!<CR>*
!<CR>                   Edit immutable change or file under the cursor.

                                                                      *jiejie_o*
o                       Open the file or |jiejie-object| under the cursor in a
                        new split.

                                                                     *jiejie_gO*
gO                      Open the file or |jiejie-object| under the cursor in a
                        new vertical split.

                                                                      *jiejie_O*
O                       Open the file or |jiejie-object| under the cursor in a
                        new tab.

                                                                      *jiejie_i*
i                       Jump to the next file or hunk, expanding inline diffs
                        automatically.

                                                                     *jiejie_[[*
[[                      Jump [count] sections backward.

                                                                     *jiejie_]]*
]]                      Jump [count] sections forward.

                                                                      *jiejie_d*
Diff maps ~
                                                                      *jiejie_=*
=                       Toggle an inline diff of the change or file under the
                        cursor.

                                                                      *jiejie_c*
Commit maps ~

                                                               *jiejie_c<space>*

                                                                     *jiejie_cc*

                                                                    *jiejie_!cn*

s<space>                Populate command line with ":Jj squash ".

                                                                     *jiejie_cs*

                                                                    *jiejie_!cS*

                                                                     *jiejie_dd*

                                                                    *jiejie_!dd*

SPECIFYING OBJECTS                               *jiejie-object* *jiejie-revision*

Jiejie objects are either work tree files or Git revisions as defined in the
"Operators" section in the jj documtenation,
https://docs.jj-vcs.dev/latest/revsets/, with expansions inspired by
|cmdline-special| layered on top. For commands that accept an optional object,
the default is the file in the index for work tree files and the work tree
file for everything else. Example objects follow.

Object          Meaning ~
@               The change referenced by @ aka HEAD
main            The change referenced by main
:               The |jiejie-summary| buffer
:./main         The file named main in the working directory
:Makefile       The file named Makefile in the work tree
:%              The current file in the work tree
@-:%            The current file in the parent of HEAD
@--:%           The current file in the grandparent of HEAD
<cfile>         The file or change under the cursor

Not yet implemented:

:(top)main      The file named main in the work tree
:1:%            The current file's common ancestor during a conflict
:2:#            The alternate file in the target branch during a conflict
:3:#5           The file from buffer #5 in the merged branch during a conflict
